# 猫狗图像二分类实验（计算机视觉实验一）

在 **100 张** 猫狗图像上，**从零训练**一个卷积神经网络完成二分类，不使用任何预训练权重。
完整实现数据划分、数据增强、训练、早停、5 折交叉验证、消融实验、可解释性可视化与推理脚本，
并自动生成一份图文并茂的中文实验报告。

### 消融实验（5 折交叉验证）

| 变体 | 准确率 | F1 | AUC | 相对完整模型 |
| --- | --- | --- | --- | --- |
| 完整模型（本文方法） | 78.00 ± 5.70 | 0.776 | 0.768 | — |
| 无数据增强 | 75.00 ± 14.14 | 0.740 | 0.742 | −3.0 |
| 无 BatchNorm | 75.00 ± 7.91 | 0.719 | 0.740 | −3.0 |

> 结论：三项正则化手段（增强 / BN / Dropout）各贡献约 3 个百分点，且移除增强后折间标准差由 5.7 涨到 14.1；
> 分辨率、宽度、TTA 基本无影响——瓶颈在样本量而非模型容量。所有差异都在 1 个标准差附近，
> 只宜作趋势判断。100 张样本从零训练，训练集准确率可达 94%–97% 而验证集徘徊在 70%–85%，过拟合明显。

## 方法要点

1. **数据**：100 张（猫 50 / 狗 50），原始尺寸 82 种，统一到 128×128；归一化均值/方差
   只由训练集统计（[0.4948, 0.4568, 0.4137] / [0.2536, 0.2470, 0.2473]），避免信息泄漏。
2. **增强**：随机裁剪缩放（0.65–1.0）、水平翻转、±12° 旋转、色彩抖动。
3. **模型**：4 个「双 3×3 卷积 + BN + ReLU + 2×2 池化」块（32→64→128→256 通道），
   全局平均池化 + Dropout(0.5) + 线性分类头；Kaiming 初始化。
4. **训练**：AdamW（lr 1e-3，wd 1e-4）、余弦退火、标签平滑 0.1、批大小 16；
   前 20 轮不参与选模，之后按验证准确率保留最佳权重并早停（耐心 25 轮）。
5. **评估**：5 折分层交叉验证给出主结果（100 张全部参与验证），
   另做 8:2 分层留出法训练最终模型用于推理；推理启用水平翻转 TTA。
6. **可复现**：所有随机源固定种子 42，重复运行结果逐位一致（已验证两次运行指标完全相同）。

## 已知局限

- 样本量极小（80 训练 / 20 验证），单折准确率标准差 5.7 个百分点，方法间 2–3 个百分点的差异多属随机波动。
- 从零训练受限于数据规模，与 ImageNet 预训练（通常 95% 以上）差距明显；
  本实验重点是完整掌握流程与分析方法，而非追求精度。
- 验证集仅 20 张：初版「从第 1 轮开始选模」会把偶然最优当成最优（准确率仅 73%），
  加入最小训练轮数约束后升至 78%——评估协议本身的影响超过多数结构改动。
- SWA（权重滑动平均）在本任务上不升反降（78% → 68%），原因是早停截断使平均窗口过短；
  该结论已写入报告第 8.2 节。
